THE DEFUSING LINE. Say the audience’s objection out loud before they can think it.

“This is a room full of people who believe in reproducibility. And I’d bet most of us, when we open a chat window, ask for the finished thing anyway.”

Entanglement

The content has no address

When an agent generates a finished document, content and structure come out woven together in a single probabilistic pass.

Nothing in it has a location.

To change one sentence, you regenerate everything — and hope.

There is no file, no line, no cell that is that sentence.

Define entanglement operationally, not metaphorically. “The content has no address” is the sticky version.

Give them the test they can apply to their own work: can you point at it?

When does it weave?

[FIGURE — “when does it weave?” diagram] Two stacked rows, identical output at the end of each. Row 1: Me → agent ⇒ document (woven here, probabilistically). Row 2: Me → agent → .qmd + data → render → same document (woven here, deterministically), plus green edit arrows from Me. 3 clicks. Source: images/entanglement-diagram/

Both approaches weave content and format together. The only question is WHEN — and by what.

The output is identical in both rows. That’s the point. The difference isn’t what comes out, it’s whether you can reach in before it does.

Optional one-liner for this room: “weave” isn’t my metaphor. It’s literate programming’s own word — Sweave, then knitr. Quarto has always been a weaving tool. I’m just arguing we should weave later.

But your prose doesn’t go in a CSV

Prose stays in the .qmd.

Its address is a line number. The agent’s edit arrives as a diff you can read in ten seconds.

Values that must be exact live in data + code.

Not just locatable — recomputed. Never typed by anyone.

The move isn’t “extract everything.” It’s “stop asking for the artifact.”

NAME THE OBJECTION FIRST. Someone is already thinking “I’m not putting my paragraphs in a spreadsheet.” They’re right, and say so.

But HTML can’t tell you it’s broken

HTML

No compile step.

Malformed output still renders as something.

.qmd

Bad cross-reference, failed chunk, invalid YAML → loud, deterministic error.

The agent reads it and fixes it — without you.

THE KILL SHOT of Act 5. This is the sharpest thing in the talk.

Documents just got a compile step. Code has had one for decades. Documents get one exactly at the moment their authors became probabilistic.

Checkable twice

By machine

quarto render is a compile step. Failures are loud and specific.

By human

Plain text means the agent’s edit is a diff. Review scales with the change, not the document.

A .docx “diff” is noise. A three-line .qmd diff is a review.

Both halves matter. git revert is a one-command undo for any agent mistake.

One honest caveat

Render passing ≠ analysis correct.

It’s the same guarantee compilation gives code — no more, no less.

State the limit plainly. It costs 10 seconds and buys more credibility than any other slide in the deck.
